# Urban Heat AI Agent

## Overview
Urban Heat AI Agent is a Streamlit application that uses AI to analyze urban heat datasets, identify patterns, generate insights, and create downloadable reports.

(Add screenshots here later)

## Features

- Upload urban heat datasets
- AI-generated summaries
- Interactive charts
- Markdown report export
- Streamlit web interface

## Technologies

- Python
- Streamlit
- Pandas
- Anthropic API
- Matplotlib

## Installation

```bash
pip install -r requirements.txt
